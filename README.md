# 🚀 About *Clocked In*  
**Stay accountable. Build habits. Keep your streak alive.**  

*Clocked In* is a group habit tracker designed to help you and your friends stay consistent with your goals. Whether you're building a fitness routine, developing a reading habit, or committing to daily mindfulness, this app ensures everyone stays on track together. 

Check out *Clocked In* in action: **https://groupclockedin.netlify.app/**  


## ✨ How It Works  

- **👥 Create or Join a Group** – Start by creating a group or joining an existing one. Each group focuses on a shared habit.  
- **📸 Daily Check-in with a Photo** – Snap and submit a photo as proof of completing your habit.  
- **🔥 Keep the Streak Alive** – The group's streak depends on *everyone* checking in. If even one person misses a day, the streak resets!  
- **⏳ Disappearing Photos** – Submissions vanish after 24 hours to keep the focus on daily progress.  
- **🔔 Reminders & Notifications** – Get alerts when it's time to check in and reminders if you haven’t posted.  
- **🎉 Stay Motivated** – Track your group’s progress and celebrate milestones together!  

## 🛠 Tech Stack  
*Clocked In* is built with modern web technologies to ensure a smooth and engaging user experience:  
- **Frontend:** [React.js + TailwindCSS]  
- **Backend:** [Javascript / Firebase]  
- **Database:** [Firestore]  
- **Authentication:** [Firebase Auth ]  
- **Hosting & Deployment:** [Netlify / Firebase]
