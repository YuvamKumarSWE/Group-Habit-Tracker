# Group-Habit-Tracker

Group-Habit-Tracker is a web application built with React and Vite that allows users to track habits collaboratively in groups. The application uses Firebase for authentication and data storage.

## Features

- User authentication
- Group creation and management
- Daily habit tracking
- Streak tracking for groups
- Image upload for habit verification

## Technologies Used

- React
- Vite
- Firebase (Authentication, Firestore)
- Tailwind CSS

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up Firebase configuration in `src/firebase.js`
4. Run the development server: `npm run dev`

For more detailed information on setup and usage, please refer to the project documentation.
